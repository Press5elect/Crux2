# Crux2 v1.0.22

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

Heavy games run faster: the graphics thread no longer spends half its time creating textures. About fifty bugs in the interface are fixed.

## Added
- **Shared Render Target Memory** and **Streamed Memory Clearing** (Settings, the Everything level; both on). At high internal resolutions the graphics thread spent about half its time creating textures: each render target had a memory allocation of its own, and the driver cleared each one and then flushed it line by line. Render targets now share memory blocks, and new memory is cleared in one pass. On a console, in a heavy game at 6x, the graphics thread went from 100% busy to 30-60%. Either can be turned off (they take effect at the next start).
- **The recomp kit makes Crux2's native modules on Windows** too: drop a game on `Crux2 Native.cmd` (they were made on Linux only). It also links large games on Windows, which failed with "The filename or extension is too long".
- The boot log names what creates textures and at what sizes, and a profile lists 40 functions on the stack (12 before).

## Changed
- Built on PCSX2 master of 2026-11-17 (`8407746`: a newer controller database, and Japanese titles in the game database). Save states are not affected.
- **Thread Pinning** shows "Dedicated Cores (Default)", which is what Crux2 has always set on a new install.

## Fixed
About fifty bugs found by a review of the interface's code. Among them:
- **The quick menu's Screenshot**, and a texture pack download or a save search ending during a game, could stop the picture or the title.
- **Covers without a connection**: every game was noted as having no cover and never asked for again. A cover download cut short no longer turns automatic covers off for good.
- **A texture pack moved onto a share** that already had one for the game was mixed with it, and the original deleted.
- **A memory card could be lost** to a power cut while it was written; a restore stopped by a game start left some cards restored and some not.
- **The on-screen keyboard**: Delete took two characters after an accented letter.
- **Controller ports 2 and up** shared port 1's rows: after "Map to Console Controller" the next press mapped another port.
- **"Internal resolution above 12x"** jumped to 25x from a normal value.
- **Quick views** kept in Showcase, Wheel, Wall or Discs came back as Table after a restart.
- **A game's own SingStar or light gun choice**, put back to the global one, kept its own USB settings.
- **A disc set's** last played, time played and favourite are now the whole set's, not the front disc's.
- Logs and What's New at larger text sizes lost the ends of their lines; the card and texture pack managers sat off-centre under 100% interface size.

## Tested
On a PS5: the test builds of this code were played. The two memory switches were measured with the profiler in a heavy game at 6x, with no fault seen in the picture; the interface with the bug fixes was used and found working. Not checked one by one on a console: each of the fifty fixes, memory cards and restores on an exFAT drive, packs moved to a share, and native modules made on Windows. On a PC: the host tests, the interface's walk-through of every screen with new checks, and the check that no setting was lost (733 settings: the two new ones).

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards, save states and settings are kept. Shaders are compiled again once after the update (the graphics driver changed).
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder (written after a crash, a hang or Save the log). Don't attach games, BIOS files, firmware or keys.
- If a game's picture is wrong, try it with Shared Render Target Memory and Streamed Memory Clearing off, and say whether that changed it.
