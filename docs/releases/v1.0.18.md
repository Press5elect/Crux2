# Crux2 v1.0.18

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

## Added
- **Settings > Folders**: add game folders from USB drives, network shares or the console's storage, and choose where the BIOS, memory cards, save states, screenshots, cheats, covers and texture replacements are kept.
- **Accurate floating point** for the FPU, VU0 and VU1 (Settings > Advanced, or a game's own Settings > Emulation; off), from PCSX2 Reliquary.
- **MihawkGen**, a third frame generation method.
- **Show the movement** (Settings > Graphics, advanced): shows what FSR 3 optical flow decided for each pixel.

## Changed
- Frame generation is lighter when no upscaler is used: frames are made at the game picture's own size.
- Accurate floating point is on for the FPU and VU0 in the two games known to need it.
- x86 emitter encoding fixes from PCSX2 Reliquary.
- Save states keep their format: v1.0.17 and v1.0.18 load each other's states.

## Fixed
- Frame generation at 120 Hz held games at 67% or 50% speed, even standing still.
- Frame generation sped up and slowed down every few seconds in games at 30 frames a second.
- Frame generation at 120 Hz made one picture between the game's instead of three when frames came unevenly.
- What's new now shows what was added, changed and fixed in each version, and opens once after an update.

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards, states and settings are kept. Shaders are compiled again once after the update.
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder, copied before Crux2 is started again. Don't attach games, BIOS files, firmware or keys.
