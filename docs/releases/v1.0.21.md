# Crux2 v1.0.21

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

A small release after v1.0.20: the menus open faster, and covers come from a second collection.

## Added
- **A second place covers are downloaded from.** A game that libretro's collection has no box art for is asked for by its serial in the `xlenore/ps2-covers` collection on GitHub and saved as `covers/<serial>.jpg`. Games found missing from libretro's before are tried there too (Settings > Games and saves > Game List, **Download Missing Covers**).

## Changed
- **The interface asks the emulator for less when a screen opens.** The quick menu with pinned settings made the settings' pages five times as it opened; the Settings and the quick menu read the whole game list, looking into the save states, cheats and textures folders, each time. Both are done once now.
- **The recomp kit links large games on Windows.** A game with thousands of functions failed at the last step with "The filename or extension is too long"; the object files are given to the linker in a file now.
- A long title is cut to its width in one pass, and discs off the side of the screen (the Discs view) are not drawn.

## Fixed
- **A game's own settings could take seconds to open** (Square on Home, a game's page) with many cheat files on the console, as after **Download Cheats for All Games**: looking for one game's files asked the console about every file in the folder, four times. The name is looked at first now. The boot log says when opening them still takes 50 ms or more.

## Tested
On a PS5, with the test build of this code (`v1.0.21-test`): the interface, with a game's settings opening as they should. On a PC: the host tests, the interface's walk-through of every screen, the check that no setting was lost, and the pictures of every screen, which are the same as v1.0.20's. Not confirmed one by one on a console: covers from the second collection for every region.

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards, save states and settings are kept (PCSX2 is the same revision as in v1.0.19 and v1.0.20).
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder (written after a crash, a hang or Save the log). Don't attach games, BIOS files, firmware or keys.
