# Crux2 v1.0.0

The PlayStation 2 emulator PCSX2 as a native homebrew title for a jailbroken PS5 (`PPSA99249`), with a Big Picture interface made for the television and the DualSense. The first release.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no BIOS files, no console firmware and no decryption keys, and none will ever be provided or linked to. Use only **legally obtained backups of games you own**, made yourself from your own discs, and a BIOS dumped from **a PlayStation 2 you own**. Please don't ask for, or post links to, games, BIOS files, firmware or keys in issues or discussions: they will be removed.

> [!NOTE]
> **An unofficial port.** This is not a build of the PCSX2 project and is not supported by it. Please don't report its problems to PCSX2.

## What's in it

Added:
- **PCSX2 on the PS5**: its x86-64 recompilers and Vulkan renderer (through RADV, linked into the title), the software renderer, save states, cheats, PCSX2's patch collection (widescreen and no-interlacing patches applied by themselves), the network adapter and hard drive for online games, RetroAchievements.
- **paraLLEl-GS**, a second GS renderer: the whole GS drawn on the graphics chip, super-sampled.
- **Games from everywhere**: the title folder, USB drives, SMB and NFS network shares, the console's disc drive and USB DVD drives. A disc can be read into memory, or made into an ISO, CHD or CSO image.
- **A Big Picture interface**: ten library views (Shelves, Grid, List, Flow, Bookcase, Table, Showcase, Wheel, Wall, Discs), search, filters, quick views, favourites and collections, covers and pictures of play, 36 skins, an animated mark, interface and text size, music of your own.
- **Settings at three levels**, Normal, Advanced and Expert (Triangle in the Settings), for all games or one game alone.
- **Picture**: up to 12x internal resolution, FSR 1, NIS and CAS, Automatic quality, frame generation, black frame insertion, 4K at 60 or 120 Hz, CRT and signal looks, HD texture packs (also downloaded from the Internet Archive's collection).
- **Saves**: a memory card for each game, a card manager that brings saves in (from a PlayStation 2 on the network, USB drives, shares or card images), sleep-safe saving, states saved by themselves with undo, backups, and memory cards kept in sync with a share.
- **Controllers**: four players, controller profiles, pressure from R2, GunCon 2 aimed by moving the controller, USB microphones, a USB keyboard, light bars, control from a phone.
- **Care for an OLED screen**, **updates** from this page (Crux2 looks at each start, and asks before downloading), a **free BIOS** fallback (OpenPS2BIOS, early work), and **native code modules** (experimental).

Default settings: 6x internal resolution with FSR 1 from 4x and Automatic quality, widescreen and no-interlacing patches, 4K output at 60 Hz paced by the screen, no on-screen display, a memory card for each game, the main threads on cores of their own, texture packs loaded and precached. Everything can be changed in Settings.

## Tested for this release

On my PS5, with the development builds this release comes from: games start and play from the internal storage, USB drives, an SMB share, the disc drive and a USB DVD drive; the network adapter, the hard drive, RetroAchievements, downloaded cheats and patches, covers, backups to a share and memory cards work. The heaviest scene I test with (a 60 fps patch, full blending accuracy, 6x) held 100% speed for all but four dips of about three seconds in a six-minute run, 59.2 frames a second on average, with the sound's time stretcher at its normal tempo 95-100% of the time.

On the PC, for this exact build: the host tests, the interface tests (every settings row changed every way, 120,000 random button presses with the sanitizers, a picture of every screen) and the release check pass.

Not tried on the console one by one: every setting, paraLLEl-GS in every game, the native code modules, many of the PS2 accessories.

## Known issues

- paraLLEl-GS is slower than PCSX2's renderer in the heaviest game I test with, and its picture is softer by design.
- The free BIOS is early work: many games reach their menus and go no further. Use a BIOS dumped from your own PlayStation 2.
- RetroAchievements' hardcore mode is not offered.

## Install or update

1. Copy the `PPSA99249` folder from the ZIP to your homebrew folder on the console (`/data/homebrew/`), over an older one if you have it.
2. Your settings, memory cards, states and games stay: with a folder `/data/crux2`, Crux2 keeps them there, outside the title folder.
3. Your own games in `games/` (or on a USB drive or a share), your own BIOS in `bios/`. None included, none ever will be.
4. Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems

Open an issue with `crux2-boot.log` and `logs/emulog.txt` from the title folder (Settings > System can copy them to a USB drive), copied before Crux2 is started again. Never attach games, BIOS files, firmware or keys.
