# Crux2 v1.0.19

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

## Added
- **SMAA anti-aliasing**: Settings > Picture > Look, beside the CRT and signal looks. A look is one preset, so SMAA replaces a CRT look.
- **Settings > Debug > Logs**: turn every log off, or choose which are kept and whether they go to the console or a USB drive.
- **Network shares in Settings > Folders**: add, change or remove an SMB or NFS share with the on-screen keyboard; the server can be found on the network.
- **Japanese, Chinese and Korean names** are drawn in the interface instead of as "?".

## Changed
- Built on PCSX2 v2.9.158 (was v2.9.150): a Vulkan fix, a guard against out-of-bounds texture reads, more Japanese serials in the game database, a newer controller database.
- Games on a network share are read faster.
- Fewer writes to the console's drive: the five-minute safety save is kept in memory (written only if Crux2 crashes), the boot log is synced only when a game starts or closes, and PCSX2's duplicate pipeline cache file is gone.
- The graphics driver backs a large buffer with several pieces of memory when no single piece is big enough.

## Fixed
- The console could go down after Crux2 was closed many times with USB drives on.
- The microphones of a karaoke game heard nothing.

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards, states and settings are kept. Shaders are compiled again once after the update.
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder, copied before Crux2 is started again. Don't attach games, BIOS files, firmware or keys.
