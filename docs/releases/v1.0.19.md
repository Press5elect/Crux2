# Crux2 v1.0.19

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

An earlier v1.0.19 was built but not published; this release is made anew from v1.0.18.

## Added
- **HDR10 output** (Settings > Graphics, HDR; off), with peak and white levels and **Adjust HDR brightness**. Needs the console's HDR setting and a TV that takes HDR.
- **Debanding** and a **colour filter for colour blindness** on the game's picture (Settings > Graphics; off).
- **A startup video** of Crux2's own (Settings > Interface, Startup video).
- **Network shares set up on the console** (Settings > Folders): servers found on the network (SMB and NFS), their shares listed, and a test that says what went wrong. Shares are woken when Crux2 starts, and a game on a share that doesn't answer waits for it with a count on the screen.
- **Light gun** (Settings > Controllers): one or two GunCon 2s plugged in with their buttons set up, steady motion aim (no drift, R3 recentres, the screen measured at two corners), R2 that clicks like a trigger, and a second gun for player 2. A **PlayStation Move** can aim player 1's gun through the Move Management payload (off).
- **Achievements as the console's trophy pop-ups**, with the trophy sound.
- **The quick menu your way**: Triangle shows, hides and orders its entries and puts a game's options in it; **Apply changes now** restarts the game for settings that need it; **Save the log**.
- **Screenshots** with Options + Square (the game's picture, no menus).
- **Game fixes fetched from GitHub** at start, so a fixed game needs no new Crux2.
- **Stick response curves**, Steady 30 for frame generation, launch arguments `--rom` and `--exit-after-game`.
- **The recomp kit** (`Crux2-recomp-kit-v1.0.19.zip`) comes with the release: it makes a game's native modules on a PC.

## Changed
- **HD texture packs download over 10 connections at once**, with a progress bar (size, speed, time left). Download connections: 1 to 16.
- **Covers download three at a time**, and the ones on screen load first.
- Quick taps are held for the game at least 50 ms, so they aren't missed.
- The boot log is kept in memory and written when something goes wrong (Settings > Log); settings are written when the menus close; an exit waits for writes under way, with a bar.
- Texture packs are held within a memory budget.
- Built on PCSX2 v2.9.179 (was v2.9.150). **Save states made with earlier versions don't load**; memory cards are not affected.
- Built with the payload SDK `3345cde` (its v0.45 base), PS5_Vulkan `7f492b4` and a new profile for profile-guided optimisation. The graphics driver stays on Mesa of 2026-10-31, as v1.0.18's.

## Fixed
- A GunCon 2 could only be plugged in by editing the settings file.
- A backup that couldn't read a file was written as complete, and could then replace the previous good one.
- Very large images are refused before they're decoded.

## Tested
On a PS5: games played with the profile-guided build (each game's first start too), the startup video, and HD texture pack downloads with the progress bar. Not yet tried on a console: the PlayStation Move, the light gun's new aim, network share setup, trophy pop-ups and the recomp kit's modules.

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards and settings are kept. Save states from earlier versions don't load. Shaders are compiled again once after the update.
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder (written after a crash, a hang or Save the log). Don't attach games, BIOS files, firmware or keys.
