# Crux2 v1.0.23

> [!IMPORTANT]
> No games, BIOS files, firmware or keys are included, and none ever will be. Use only legally obtained backups of games you own and a BIOS dumped from your own PlayStation 2.

Freezes in the interface are fixed, anti-aliasing can be set per game and no longer raises the resolution, and the M.2 storage can hold games.

## Added
- **Games on the M.2 storage** (`/mnt/ext1`) and on `/mnt/ext0`: a folder named `crux2`, `ps2` or the like at the top is found as on a USB drive, and both are offered in the folder browser, for copying a disc, exporting saves and shader presets.
- **Anti-Aliasing, SSAA Filter and Debanding** can be set for one game.
- Test runs say more about where the graphics chip's time goes: what each conversion pass does (copies, depth conversions, deinterlacing, merging, clears), the pixels shaded by each kind of pass, and why the graphics thread waited for an image (the screen's pace, the GPU, a full queue; a patch to the graphics driver).
- **IOP Stores Inline**, **Skip Unchanged Microprograms**, **Coarse Thread Times** and **Wake-Up Spin Time** (Settings, the Everything level; off, or as before).

## Changed
- **SSAA** scales the picture of the internal resolution you chose down to the screen; it no longer raises the resolution to 8x at 4K. FSR 1 is off while SSAA is chosen, and comes back when another choice is made.
- **Driver Core Kept Free** is on: the emulator's other threads stay off the graphics driver's core.
- The game page's settings tab is **Game Specific Settings** (and so are the quick menu's tile and the page's card); the file card is **Game File**.
- PCSX2's messages on screen look like Crux2's own.
- Faster paths in the CPU emulation, the VU thread, the GS and the audio's time stretch, each giving the same results as before. In the games measured they changed no frame rate: those are held back by the graphics chip, not by these paths.
- The profile the title is compiled with is trained again on these sources.

## Fixed
- **Choosing a memory card or changing a memory card setting could freeze the interface and the game**: the Memory cards page opened every card (a folder card's saves all read) each frame it was shown.
- **Loading texture packs again soon after a game with a pack started** (a game closed, a texture setting changed, a pack download ended) could freeze the picture and the interface for tens of seconds or minutes.
- **A file written to a network share** (a card sync, a backup, a pack moved there) held up everything else on that share until it was written, the game's picture among them.
- **Pinned settings**: the Settings home showed only the four oldest pins. It shows them in the quick menu's order and scrolls through the rest.
- A resolution that SSAA had raised stayed raised after SSAA was turned off. It is put back now; one raised by an older version is not known: lower it by hand.

## Tested
On a PS5: the release candidate of this code and the test builds before it were played. Three GPU-heavy games ran at 99% speed on average at 6x (at 8x one of them fell to 93%: the graphics chip is the limit there); three more were played while training the profile. The memory card, texture pack and pin fixes were used and found working. Not checked on a console: games on the M.2 storage (no drive was fitted), Driver Core Kept Free on (it was tried off), and the four new switches with them on. On a PC: the host tests, the interface's walk-through of every screen, the check that no setting was lost, and the release check of the ZIP.

## Installation
- Copy the `PPSA99249` folder to `/data/homebrew/` on the console, over an older one if you have it.
- Your games, BIOS files, memory cards, save states and settings are kept. Shaders are compiled again once after the update (the graphics driver changed).
- If you used SSAA in an older version, check that the internal resolution is the one you want (it was raised for SSAA).
- Read `LEGAL.txt` and `README.md` in the folder.

## Reporting problems
- Open an issue and attach `crux2-boot.log` from the title folder (written after a crash, a hang or Save the log). Don't attach games, BIOS files, firmware or keys.
- If a game runs slower than in v1.0.22, try it with Driver Core Kept Free off, and say whether that changed it.
