# The v1.0.19 and v1.0.20 work (reverted)

Between the v1.0.18 release (tag `v1.0.18`, 2026-11-01) and 2026-11-09 this branch carried two more
versions' work. On 2026-11-09 the owner asked to go back to the release on GitHub, and 883c832
reverted the branch to the v1.0.18 tree (its tree is identical to the tag's). The commits stay in
history before 883c832.

- **v1.0.19 was built (build 59, from `a1a2554`; notes written in 4130491) but never tagged or
  published.**
- **v1.0.20 was prepared (3718e4f, notes in c435d21 with the build fields still `TODO`) and never
  built as a release.**
- The published releases end at v1.0.18 ([`../releases/README.md`](../releases/README.md)).

## How to bring it back

All of it: `git revert 883c832` (then rebuild, re-export `ps5.patch`, rebuild RADV). Part of it:
`git show <commit>` or `git cherry-pick <commit>` from the list below, resolving against what came
after (b075fe1 changed many of the same files: `bp_pcsx2.cpp`, `ps5_platform.cpp`, `ps5_logs.*`,
`ps5.patch`). The old texts are readable without checking anything out:

```bash
git show 2bf2d08:CHANGELOG.md                  # the v1.0.19 and v1.0.20 changelog sections
git show 2bf2d08:docs/releases/v1.0.19.md      # its notes, as written
git show 2bf2d08:docs/releases/v1.0.20.md
git show 2bf2d08:README.md                     # the README with "What v1.0.19/v1.0.20 changed"
```
